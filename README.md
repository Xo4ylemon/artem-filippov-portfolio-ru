# Профессиональное портфолио

Участвую в исследовании лазерной декапсуляции интегральных микросхем для задач обратного проектирования. 10 ноября 2026 года представил проект на Международной ассамблее молодых изобретателей в Великом Новгороде. Стенд вошёл в репортаж «России 1»; после мероприятия было записано отдельное интервью областному телевидению.

- Исследование влияния параметров лазерной обработки на удаление материала корпуса.
